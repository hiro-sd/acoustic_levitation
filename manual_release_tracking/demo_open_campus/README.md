# 月のかけら救出ミッション

自由落下球体の捕捉実験と同時に表示する、子ども向けの独立画面です。制御ループに処理を追加せず、`auto_release_capture_events.csv` に新しく追記されたイベントだけを監視します。

Windows PowerShell で、捕捉実験とは別のターミナルから実行します。

```powershell
.\venv_autd3\Scripts\python.exe manual_release_tracking\demo_open_campus\moon_fragment_mission.py
```

操作は次の通りです。

- `Space`: タイトル → 約15秒の導入ストーリー → 準備画面 → 3秒カウントダウン。ストーリー中に押すと準備画面までスキップできます。成功または失敗画面から次の体験へ戻るときにも使います。
- `0`: どの画面からでもタイトル兼アニメーション開始画面に戻ります。テンキーの`0`にも対応しています。
- `Esc`: 画面を終了。
- `Enter`: AUTDなしのリハーサル用に解放を疑似。
- `S` / `F`: 成功・失敗画面の表示テスト。
- `R`: 準備画面へ戻る。

実験側が `release_candidate_command_enqueued` を記録すると「超音波ネット展開中」に切り替わります。`capture_braking_to_local_hold` 到達後、解放から2秒間停止イベントがなければ成功と表示します。2秒以内に `automatic_field_stopped` が記録された場合や、4秒以内に保持段階へ到達しない場合は、ロボット回収の失敗画面へ移行します。この2秒判定は展示用であり、論文用ログの5秒成功判定は変更しません。

## 球体捕捉シミュレータ

`capture_simulator.html` をブラウザで開くと、模式データをすぐ再生できます。実験ログを再生する場合は、画面上部から `trial_timeseries.csv` と `trial_summary.csv` を同時に選択します。試行選択、再生・一時停止、速度変更、時間スライダー操作ができます。

- XZ表示: 実測軌跡、水色の自由落下予測、緑色の制動参照軌道、計画停止位置
- XY表示: 球体、実測軌跡、焦点群中心、水平自由運動予測
- 下段: 鉛直速度と超音波強度の時系列

水色の予測は、選択時刻の実測位置・速度から重力のみを仮定して120 ms先まで計算した展示用の予測です。制御器が当時実際に使用した初期予測点は、`trial_summary.csv`を同時に読み込んだ場合に別のマーカーで表示します。
